## Hello GitHub Fans 👋

Hi guys, I'm **Pratham Shukla**. I'm a data and machine-learning engineer with around five years of hands-on
experience taking models past the notebook and into services people can actually call.
I also build reverse-engineering and security tooling, so contact me if you're working on something interesting or have questions!

- 🔭 Building **[Trinetra](https://github.com/prathamshukla28/trinetra)**, a CLI that reverse-engineers, audits and rebuilds software
- 🧠 Focus: applied ML, MLOps, data pipelines, leak-free and reproducible training
- 🛠️ Shipping tested FastAPI services in Docker, with CI on GitHub Actions
- 💼 Open to **ML / Data Engineer** roles
